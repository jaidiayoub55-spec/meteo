# Météo - XML

## Description
Ce projet consiste à créer un document XML permettant de représenter des données météorologiques pour différentes villes, notamment les dates de mesure et les températures enregistrées.

## Technologies utilisées
- **XML** : Structuration des données météorologiques.
- **DTD** : Définition et validation de la structure du document XML.
- **XSD** : Vérification de la structure et des types de données.
- **XSLT** : Transformation du document XML en une page HTML.

## Fonctionnalités
- Affichage des dates des mesures météorologiques.
- Affichage des noms des villes.
- Affichage des températures enregistrées.
- Présentation des résultats sous forme de tableau HTML.

## Objectif
Mettre en pratique les notions de structuration, de validation et de transformation des documents XML à travers un exemple de données météorologiques.
